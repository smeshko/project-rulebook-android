# Rulebook Android - Development Setup Guide

**Last Updated:** 2025-12-19

This guide walks you through setting up your development environment for the Rulebook Android application.

---

## Prerequisites

### Required Software

#### 1. Android Studio (Required)
- **Version:** Hedgehog (2023.1.1) or later (Iguana/Jellyfish recommended)
- **Download:** https://developer.android.com/studio
- **Includes:**
  - IntelliJ IDEA-based IDE
  - Android SDK
  - Android Emulator
  - JDK 17 (bundled)

#### 2. Git (Required)
- **Version:** 2.30 or later
- **macOS:** Pre-installed or via Homebrew (`brew install git`)
- **Windows:** https://git-scm.com/download/win
- **Linux:** Via package manager (`sudo apt install git`)

#### 3. JDK (Bundled with Android Studio)
- **Version:** JDK 17 (bundled with Android Studio)
- **Alternative:** Download from [Adoptium](https://adoptium.net/) if needed

### Optional Tools
- **Scrcpy:** Screen mirroring for physical device testing
- **Android Debug Bridge (adb):** Command-line device management (included with Android Studio)
- **Postman/Insomnia:** API testing during development

## Environment Setup

### Step 1: Install Android Studio

1. **Download Android Studio**
   - Visit https://developer.android.com/studio
   - Download the latest stable version for your platform

2. **Run the Installer**
   - **macOS:** Drag Android Studio.app to Applications folder
   - **Windows:** Run the .exe installer
   - **Linux:** Extract .tar.gz and run `studio.sh`

3. **Complete Setup Wizard**
   - Choose "Standard" installation type
   - Download the recommended Android SDK components
   - Accept license agreements
   - Wait for initial SDK downloads to complete

### Step 2: Configure Android SDK

1. **Open SDK Manager**
   - Android Studio → Settings/Preferences → Appearance & Behavior → System Settings → Android SDK

2. **Install Required SDK Platforms**
   - ✅ Android 15.0 (API 35) - Target SDK
   - ✅ Android 14.0 (API 34) - Minimum SDK

3. **Install SDK Build Tools**
   - ✅ Android SDK Build-Tools (latest)
   - ✅ Android SDK Platform-Tools
   - ✅ Android SDK Tools

4. **Install Additional Components (SDK Tools Tab)**
   - ✅ Android Emulator
   - ✅ Android SDK Platform-Tools
   - ✅ Intel x86 Emulator Accelerator (HAXM) - for Intel Macs/Windows
   - ✅ Google Play services

### Step 3: Set Up Environment Variables (Optional but Recommended)

#### macOS/Linux
Add to `~/.zshrc` or `~/.bash_profile`:

```bash
export ANDROID_HOME=$HOME/Library/Android/sdk  # macOS
# OR
export ANDROID_HOME=$HOME/Android/Sdk  # Linux

export PATH=$PATH:$ANDROID_HOME/emulator
export PATH=$PATH:$ANDROID_HOME/platform-tools
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin
```

Apply changes:
```bash
source ~/.zshrc  # or ~/.bash_profile
```

#### Windows
1. Open System Properties → Environment Variables
2. Add new System Variables:
   - `ANDROID_HOME` = `C:\Users\<YourUsername>\AppData\Local\Android\Sdk`
3. Edit `Path` variable, add:
   - `%ANDROID_HOME%\platform-tools`
   - `%ANDROID_HOME%\emulator`

## Project Setup

### Step 1: Clone the Repository

```bash
cd ~/Developer/Projects  # or your preferred directory

git clone <repository-url> project-rulebook-android
cd project-rulebook-android
```

### Step 2: Open Project in Android Studio

1. **Open Android Studio**
2. **Select "Open an Existing Project"**
3. **Navigate to project directory** and select it
4. **Wait for Gradle Sync**
   - First sync will download all dependencies (may take 5-10 minutes)
   - Progress shown in bottom status bar

### Step 3: Configure Local Properties

Create `local.properties` file in project root (if not auto-generated):

```properties
## This file is automatically generated by Android Studio.
## Do not modify this file -- YOUR CHANGES WILL BE ERASED!
##
# Location of the android SDK. This is only used by Gradle.
sdk.dir=/Users/<YourUsername>/Library/Android/sdk
```

### Step 4: Set Up Signing Configuration (Optional - for Release Builds)

For debug builds, Android Studio generates a debug keystore automatically. For release builds:

1. **Generate a keystore** (one-time setup):
```bash
keytool -genkey -v -keystore rulebook-release.keystore \
  -alias rulebook -keyalg RSA -keysize 2048 -validity 10000
```

2. **Create `keystore.properties`** in project root:
```properties
storePassword=<your-store-password>
keyPassword=<your-key-password>
keyAlias=rulebook
storeFile=/path/to/rulebook-release.keystore
```

3. **Add to `.gitignore`** (already included):
```
keystore.properties
*.keystore
*.jks
```

## Running the Application

### Option 1: Run on Android Emulator (Recommended for Development)

#### Create an Emulator (First Time)

1. **Open Device Manager**
   - Tools → Device Manager (or click device icon in toolbar)

2. **Create Virtual Device**
   - Click "Create Device"
   - **Phone Category:** Select "Pixel 6" or "Pixel 7"
   - Click "Next"

3. **Select System Image**
   - **Recommended:** Android 15 (API 35) - UpsideDownCake
   - Download if not already installed
   - Click "Next"

4. **Configure AVD**
   - **AVD Name:** Pixel_6_API_35
   - **Startup Orientation:** Portrait
   - **Graphics:** Hardware (if available, otherwise Automatic)
   - Click "Finish"

#### Run the App on Emulator

1. **Select Device:** Choose your emulator from device dropdown
2. **Select Configuration:** "app" (should be default)
3. **Click Run:** Green play button or `Shift + F10` (Windows/Linux) / `Control + R` (macOS)
4. **Wait for Deployment:** Emulator will start automatically if not running

### Option 2: Run on Physical Device

#### Enable Developer Options on Device

1. **Open Settings** on your Android device
2. **Navigate to "About Phone"**
3. **Tap "Build Number" 7 times** until "You are now a developer!" appears
4. **Go back to Settings**
5. **Open "Developer Options"**
6. **Enable "USB Debugging"**

#### Connect Device and Run

1. **Connect via USB cable**
2. **Authorize Computer:** Tap "Allow" when USB debugging prompt appears on device
3. **Verify Connection:**
   ```bash
   adb devices
   ```
   Should show your device with status "device"

4. **Select Device:** Choose your device from device dropdown in Android Studio
5. **Click Run:** Green play button

### Option 3: Build APK/Bundle

#### Debug APK
```bash
./gradlew assembleDebug
```
Output: `app/build/outputs/apk/debug/app-debug.apk`

#### Release APK (requires signing configuration)
```bash
./gradlew assembleRelease
```
Output: `app/build/outputs/apk/release/app-release.apk`

#### App Bundle (for Play Store)
```bash
./gradlew bundleRelease
```
Output: `app/build/outputs/bundle/release/app-release.aab`

## Running Tests

### Unit Tests (Runs on JVM)

```bash
# Run all unit tests
./gradlew test

# Run tests for specific module
./gradlew :app:test
./gradlew :feature:camera:test

# Run with coverage
./gradlew testDebugUnitTest jacocoTestReport
```

### Instrumented Tests (Requires Emulator/Device)

```bash
# Run all instrumented tests
./gradlew connectedAndroidTest

# Run tests for specific module
./gradlew :app:connectedAndroidTest

# Run specific test class
./gradlew connectedAndroidTest \
  -Pandroid.testInstrumentationRunnerArguments.class=com.rulebook.ExampleTest
```

### Run Tests from Android Studio

1. **Navigate to test file**
2. **Right-click on test class or method**
3. **Select "Run 'TestName'"** or `Ctrl+Shift+F10` (Windows/Linux) / `Control+Shift+R` (macOS)

## Troubleshooting

### Common Issues

#### Gradle Sync Failed
**Problem:** "Gradle sync failed: Could not resolve dependencies"

**Solutions:**
1. Check internet connection
2. Clear Gradle cache:
   ```bash
   ./gradlew clean --refresh-dependencies
   ```
3. Invalidate caches in Android Studio:
   - File → Invalidate Caches → Invalidate and Restart

#### Emulator Won't Start
**Problem:** Emulator fails to launch or shows black screen

**Solutions:**
1. Check virtualization is enabled in BIOS (Intel VT-x/AMD-V)
2. Reinstall emulator:
   - SDK Manager → SDK Tools → Uninstall/Reinstall Android Emulator
3. Try different graphics mode:
   - Device Manager → Edit AVD → Graphics: Automatic/Software/Hardware

#### Build Error: "SDK location not found"
**Problem:** `local.properties` missing or incorrect

**Solution:**
Create/update `local.properties`:
```properties
sdk.dir=/Users/<YourUsername>/Library/Android/sdk  # macOS
# OR
sdk.dir=C\:\\Users\\<YourUsername>\\AppData\\Local\\Android\\Sdk  # Windows
```

#### Out of Memory Error During Build
**Problem:** Gradle build fails with OutOfMemoryError

**Solution:**
Increase heap size in `gradle.properties`:
```properties
org.gradle.jvmargs=-Xmx4096m -XX:MaxMetaspaceSize=1024m
```

#### ADB Device Not Found
**Problem:** Physical device not showing in Android Studio

**Solutions:**
1. Enable USB debugging on device
2. Reconnect USB cable
3. Restart adb:
   ```bash
   adb kill-server
   adb start-server
   ```
4. Check USB cable supports data transfer (not charge-only)

## Development Workflow

### Daily Development Flow

1. **Pull Latest Changes**
   ```bash
   git pull origin staging
   ```

2. **Create Feature Branch**
   ```bash
   git checkout -b feature/RULE-XXX-description
   ```

3. **Start Android Studio**
   - Open project
   - Wait for Gradle sync
   - Select emulator/device

4. **Develop & Test**
   - Write code
   - Run app frequently to test changes
   - Run relevant unit tests

5. **Commit Regularly**
   ```bash
   git add .
   git commit -m "feat(camera): add zoom gesture support"
   ```

6. **Push and Create PR**
   ```bash
   git push origin feature/RULE-XXX-description
   ```
   - Create PR targeting `staging` branch
   - Request code review

### Testing Checklist Before Commit

- [ ] Project builds successfully: `./gradlew build`
- [ ] Unit tests pass: `./gradlew test`
- [ ] No lint errors: `./gradlew lint`
- [ ] App runs on emulator without crashes
- [ ] Code follows project conventions
- [ ] Commit message follows conventional commits format
