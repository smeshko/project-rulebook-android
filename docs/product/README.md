## Product Summary

**Rulebook** - "From box to playing in 60 seconds"

An Android app that lets users photograph any board game box and receive AI-generated, digestible rules within 60 seconds.

### Key Features

- Photo-to-rules AI pipeline
- Progressive disclosure: Setup → First Round → Deep Dive
- Offline-first game library
- Credit-based monetization

### Success Metrics

| Metric | Target |
|--------|--------|
| Scan-to-rules | <60 seconds |
| Crash-free sessions | >99% |
| Day 7 retention | >20% |
| Free → Paid conversion | >5% |
