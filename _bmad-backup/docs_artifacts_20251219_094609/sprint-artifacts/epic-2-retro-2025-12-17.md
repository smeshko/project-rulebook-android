## Challenges

### Issues Encountered

- **JDK 25 / Gradle 8.9 compatibility** - Continued blocking local build verification (Stories 2.3, 2.5) - carryover from Epic 1
- **BackHandler vs Predictive Back conflict** - Manual BackHandler was blocking preview animations (Story 2.8)
- **Android framework test dependencies** - Some tests required instrumented tests due to icon initialization

### Root Causes

- JDK environment issue not resolved from Epic 1 action items
- Compose Navigation 2.8 predictive back behavior not well documented
- Material icons require Android context for initialization

### Impact

- Build verification required Android Studio JBR workaround
- Story 2.8 required code review fix to remove interfering BackHandler
- Some unit tests moved to instrumented tests

---

## Key Insights

1. **Compose Navigation 2.8 predictive back works automatically** - Don't add manual BackHandler if you want preview animations
2. **JDK environment issues compound over time** - Should have been priority after Epic 1
3. **Parallel story execution works** - Dependency flowchart was accurate
4. **Brutalist design system scales well** - Easy to apply to new components
5. **State preservation is crucial** - saveState/restoreState pattern for tab navigation
